# Site outline

Parent/child page structure from the NSF Web Outline V2 and the content plan index. Numbers match the doc titles in the Drive folder "NSF Website Pages", so migration (build plan step 17) sets each page's parent from its number.

Each page's slug follows the content plan (NSF Website Content Sheets, CONTENT PLAN tab): a page paired with an old-site page keeps that page's slug, shown with the old URL it comes from. New pages take a slug from their title. A page's URL is its parents' slugs plus its own.

Main menu: National Programs, Sleep Health Resources, Research, SleepTech®, SleepMark®.
Utility menu: About Us, Contact, Media Center.
