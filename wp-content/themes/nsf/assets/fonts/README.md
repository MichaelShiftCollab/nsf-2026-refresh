# Fonts

- `open-sans/`: Open Sans variable (weight 300–800, Latin subset), from Fontsource. SIL Open Font License.
- Test Family (H1, H2): not here yet. Shift is licensing Klim's Family; until the files arrive the `test-family` preset falls back to Georgia. To add it, drop the WOFF2 files in `test-family/` and add a `fontFace` entry to the `test-family` font family in `theme.json`. Swapping to Family later is a change to that one entry.
